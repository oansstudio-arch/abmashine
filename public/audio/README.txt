Abmashine™ voice coach recordings

Drop your own MP3 files into this folder (public/audio) using exactly these file names.
Any file that is missing falls back automatically to the browser's English voice,
and Settings shows each clip as "custom recording" or "synthetic voice".

  welcome.mp3            – played when a challenge starts
  morning.mp3            – morning greeting
  workout_start.mp3      – start of a session
  exercise_complete.mp3  – after each exercise
  rest_start.mp3         – start of a rest period
  workout_complete.mp3   – session finished
  motivation.mp3         – motivation line on the dashboard
  reminder.mp3           – session reminder
  goal_reached.mp3       – personal goal achieved
  challenge_complete.mp3 – whole challenge finished
